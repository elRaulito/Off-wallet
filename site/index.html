The threat surface

The safest network stack is the one that was never built.

Most wallet compromises arrive through something the device does for you: a radio, a driver, an update, a dependency. A 1998 handheld does none of them.

No radio, no port, no stack

No Wi-Fi, no Bluetooth, no cellular, no USB data. The only ways in or out are the screen, the speaker and eight buttons. There is no network code anywhere in the ROM to attack, because there is nothing for it to talk to.

Nothing that updates itself

No operating system, no services, no package manager, no auto-update. The wallet is a single 128 KB ROM image you can rebuild from source and hash yourself — the same bytes every time.

Nothing to phone home to

No telemetry, no analytics, no remote configuration, no runtime dependencies. Nothing on the console can be socially engineered, prompt-injected or silently swapped, because nothing on it is listening.

How it works

A starter, an egg, and a key that never leaves the cartridge.

The interface borrows the opening of a monster-collecting game, because the parts that matter — gathering randomness, then waiting out a slow computation — are exactly what that opening is made of.

Entropy

You watch your key being made, flip by flip.

The console has no hardware random number generator, and it does not pretend to have one. Every button press is one coin flip, and it lands on the grid the instant it happens: 128 presses, 128 bits, the whole secret in front of you before anything is computed from it.

  • Each flip is the parity of the press instant, resolved to a few µs — no finger aims that finely
  • Those bits are the key: on the 12-word path they are the BIP-39 entropy itself
  • Heads, tails and the longest run are tallied on screen — SELECT throws a lopsided sequence away

Derivation

Real taproot, computed on an 8-bit CPU.

secp256k1 arithmetic written for a processor with no multiply instruction. The 256×256-bit multiply is hand-written assembly that never multiplies: it precomputes shifted copies and adds them, which took one field multiply from 167 ms to 24 ms.

  • BIP-341 tweak, bech32m address, witness version 1 — a plain bc1p…
  • Or 12 BIP-39 words at the standard path m/86'/0'/0'/0/0
  • Scalar multiplication by Lim–Lee comb; inversion by libsecp256k1's addition chain

Receiving

A QR code drawn 111 pixels wide.

Nobody should retype 62 characters. The console builds a real QR code — version 3, error-correction level L, 29×29 modules at three pixels each — and a phone reads it straight off the screen.

  • Encoder written from scratch: Galois field, Reed–Solomon, mask penalties
  • Its 196 unique tiles live in the console's second VRAM bank, so the font survives
  • Verified by pointing a real QR reader at the emulated framebuffer

Spending

The cartridge keeps. Your wallet spends.

OffWallet does not sign transactions, on purpose. A wallet that signs incorrectly is worse than one that does not sign at all — so when you want to move coins, you take the secret to software that handles fees, change and broadcast properly.

  • Single key exports as an ordinary WIF: import as tr(<key>)
  • Or restore the 12 words in any BIP-39 wallet and pick the taproot account
  • The MY UTXOS screen keeps your own ledger: txid, index, amount, balance

Threat model

What it is, and what it is not.

Air-gapping removes a whole class of attacks. It does not remove the ones that come with holding your own keys on hardware you can put in a drawer — so here is the whole picture, both halves of it.

What being offline really buys you

Attacks that need a route to the device stop existing.

  • Remote compromise. No radio and no network stack means no remote attack surface at all.
  • Malicious updates. Nothing on the console updates itself; the ROM is the same bytes you built.
  • Runtime supply chain. No dependencies execute at run time — the tables are generated, checked in, and re-provable.
  • Exfiltration. The key has no path out except the screen, and you decide what goes on it.

What it does not protect you from

Read this part twice before it holds anything.

  • Someone holding the cartridge. A saved key sits in plain SRAM. Whoever has the cart has the coins — treat it like cash.
  • Flipping in an emulator. Scripted input repeats exactly and the flips come out patterned. Flip the key on real hardware, with real fingers.
  • Side channels. Nothing here is hardened; the scalar multiplication's timing depends on the key.
  • Time. Cartridge batteries die and SD cards rot. Copy the secret onto paper, today.

Put it on a cartridge.

OffWallet is one 128 KB ROM. It runs on a flash cart in a real Game Boy Color — the machine you already trust not to have Wi-Fi. Everything is open source, and building from source reproduces the same bytes.
